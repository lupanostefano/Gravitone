# Code of conduct

Gravitone follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, criticise code rather than people, and help newcomers. Harassment and personal
attacks are not accepted in issues, pull requests or anywhere else the project lives.

To report a problem, use the maintainer's contact on the [GitHub profile](https://github.com/lupanostefano) or GitHub's
reporting tools. Reports are handled privately.
